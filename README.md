# TOEIC Typing (macOS デスクトップアプリケーション)

大学生・英語学習者向けの洗練されたUI/UXを備えた、TOEIC英単語タイピングゲームのmacOSデスクトップアプリケーションです。

## 主な機能・特徴

- **macOS ネイティブ体験**:
  - ウィンドウに溶け込むモダンなタイトルバー（トラフィックライト対応、ドラッグ移動対応）
  - システムネイティブメニュー（Cmd+Q, Cmd+W, リロード, フルスクリーン等）
  - Finder連携: ヘッダーの「単語フォルダ」ボタンまたは `Cmd+O` で単語テキストの保存場所を直接開いて編集可能
- **ソリッドで洗練されたデザイン (Anti-AI-Template Aesthetic)**:
  - Linear/Vercelライクな落ち着きのあるダークテーマ (`#09090b`)
  - ミニマルで機能的なタイポグラフィと精密なレイアウト
- **タイピング学習システム**:
  - List 1〜20 の単語セットおよび全リストから出題される Random All (5分チャレンジ)
  - ブラインド入力が鍛えられる Hard Mode（初期文字のみ表示、タイプミス時はヒント表示）
  - ゲーム終了後のスコア・精度・ヒントを頼った苦手単語のレビュー機能

## 起動・実行方法

### 1. デスクトップアプリとして起動（開発モード）
```bash
./run.sh
# または
npm run app
```

### 2. スタンドアロンの Mac アプリ (`.app`) をビルドする
```bash
./run.sh build
# または
npm run dist:mac
```
ビルドが完了すると、`release/mac-arm64/TOEIC Typing.app` が生成されます。そのままダブルクリックまたは `./run.sh open` で起動できます。

### 3. Webブラウザ版として起動
```bash
./run.sh web
# または
npm run dev
```

## 単語リストの追加・編集方法

単語リストはプロジェクト直下の `words/` フォルダにあるテキストファイル（`1.txt`〜`20.txt`）で管理されています。
デスクトップアプリの右上にある **「単語フォルダ」** ボタンをクリックするか、Finderで `words` フォルダを開き、通常のテキストエディタで編集できます。

フォーマット（カンマ区切り）：
```text
english_word,日本語訳
```
例：
```text
revenue,収益・歳入
negotiate,交渉する
```
変更内容は次回リスト読み込み時に即座に反映されます。

## スマホ版 (PWA)

`main` ブランチに push すると GitHub Actions が自動でビルドし、GitHub Pages に公開されます。

- 公開URL: https://zawasow30.github.io/toeic-typing/
- iPhone: Safari で開き「共有」→「ホーム画面に追加」
- Android: Chrome で開き「ホーム画面に追加」/「アプリをインストール」

横向き専用です。スマホでは画面内に専用キーボードが表示されます。
